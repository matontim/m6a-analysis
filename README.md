# M6A Cell Lines Analysis

Downstream analysis of m6Anet output across naive, astrocyte, IGF2BP2-KD, and ALKBH5-KD conditions for the Gli36 cell line, using the m6AnetAnalyzer R package.

## Overview

This repository analyzzes m6A modification predictions generated by m6Anet from Oxford Nanopore direct RNA sequencing (DRS) data across four conditions. Using m6AnetAnalyzer, it performs: 
- Quality control summaries of m6Anet site level predictions
- Dataset filtering through a user-defined threshold 
- Transcript region analysis
- Chromosomal annotation
- Weighted modification ratio calculation
- Incorporation with external annotations
- Comparative analysis

### Requirements
 
- R ≥ 4.0

Follow the installation instructions in the [m6AnetAnalyzer README](https://github.com/hannalee809/m6AnetAnalyzer#installation). 
 
See [Notes and Limitations](#notes-and-limitations) below for a couple of install issues encountered while setting this up.

## Data

This project uses publicly available data from (cite paper), hosted on Harvard Dataverse.

**Dataset:** https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/8TFC38

Each file represents pooled replicates (n=3) using m6Anet's pooling functionality. Download files using the Comma Separated Values option on Dataverse, and place them in the corresponding subfolder. The data is not tracked in git due to file size (see .gitignore).

A matching GTF annotation file is also required for transcript region/biotype annotation steps, and is downloaded separately (include instructions).
