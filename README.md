# m6A Cell Lines Analysis
 
Downstream analysis of m6Anet output across naive, METTL, IGF2BP2-KD, and ALKBH5-KD conditions for the Gli36 cell line, using the [m6AnetAnalyzer](https://github.com/hannalee809/m6AnetAnalyzer) R package.
 
## Overview
 
This repository analyzes m6A modification predictions generated by [m6Anet](https://github.com/GoekeLab/m6anet) from Oxford Nanopore direct RNA sequencing (DRS) data across four conditions. Using `m6AnetAnalyzer`, it performs:
 
- Quality control summaries of m6Anet site-level predictions
- Dataset filtering through a user-defined probability threshold
- Transcript region and biotype annotation of m6A sites
- Chromosomal distribution analysis
- Weighted modification ratio (WMR) calculation
- Incorporation with external genomic annotations (e.g., RBP binding sites)
- *(Planned)* Comparative methylation analysis across conditions

## Setup
 
### Requirements
 
- R ≥ 4.0

Follow the installation instructions in the [m6AnetAnalyzer README](https://github.com/hannalee809/m6AnetAnalyzer#installation), which covers required Bioconductor/CRAN dependencies and installing the package itself via `devtools::install_github()`.

## Data
 
This project uses publicly available data from the lab's cell lines paper, hosted on Harvard Dataverse:
 
**Dataset:** https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/8TFC38
 
| Condition | File |
|---|---|
| Naive | `pooled_naive_2025_data.site_proba.csv` |
| METTL | `pooled_2025_mettl_data.site_proba_split.csv` |
| IGF2BP2 KD | `pooled_igf_2025_m6a.csv` |
| ALKBH5 KD | `pooled_alk_2025_data.site_proba.csv` |
 
Each file represents pooled replicates (n=3) using m6Anet's pooling functionality. Download files using the **Comma Separated Values** export option on Dataverse and place them in the corresponding `data/<condition>/` subfolder (not tracked in git — see `.gitignore`).
 
A matching GTF annotation file is also required for transcript region/biotype annotation steps. Download it separately and place it in `data/GTF_annotation/`:
 
```bash
wget https://ftp.ebi.ac.uk/pub/databases/gencode/Gencode_human/release_45/gencode.v45.annotation.gtf.gz
```
 
## Workflow
 
Steps 1–5 have been completed for the naive condition. Steps for remaining conditions and comparative analysis are currently in progress.
 
1. Load m6Anet per-site probability output and compute QC summary statistics
2. Filter m6A sites by a user-defined probability threshold (`prob_modified = 0.9`)
3. Annotate m6A sites with transcript region, biotype, and chromosomal distribution
4. Calculate weighted modification ratios (WMR) per transcript
5. Convert to genomic coordinates and incorporate external genomic annotations (e.g., RBP binding sites)
6. *(Planned)* Comparative methylation analysis across conditions
Scripts implementing each step live in `scripts/`, numbered by condition in execution order.
 
## Notes and Limitations
 
Several issues were encountered during setup and use of this analysis. These have been [reported upstream](https://github.com/hannalee809/m6AnetAnalyzer/issues).
 
### Installation issues
 
Five namespace issues were found where functions from `dplyr` and `txdbmaker` are called without namespace prefixes, causing them to resolve to the wrong function or fail entirely:
 
| File | Location | Issue | Fix |
|---|---|---|---|
| `vignettes/m6AnetAnalyzer.Rmd` | ~line 540, `simulate_wmr_replicate()` | bare `n()` | `dplyr::n()` |
| `R/run_wmr_differential_test.R` | lines 54, 95 | bare `ungroup()` | `dplyr::ungroup()` |
| `R/create_bed_file.R` | ~line 34 | bare `select()` resolves to `AnnotationDbi::select` | `dplyr::select()` |
| `R/get_transcript_region_lengths.R` | line 25 + `@importFrom` | `GenomicFeatures::makeTxDbFromGFF()` (defunct) | `txdbmaker::makeTxDbFromGFF()` |
| `R/map_relative_tx_regions_to_m6A.R` | line 15 `@importFrom` | `GenomicFeatures::makeTxDbFromGFF` (defunct) | `txdbmaker::makeTxDbFromGFF()` |
 
**Workaround:** Clone the repo locally, apply all fixes above, and install from the patched local copy:
 
```r
devtools::install_local("~/path/to/m6AnetAnalyzer", build_vignettes = TRUE, force = TRUE)
```
 
Note: Pandoc must be installed (e.g., `brew install pandoc`) for vignette building to work.
 
### Runtime/documentation issues
 
- **`annotate_m6a()` input — vignette uses built-in example dataset:** In section 5.2, the vignette passes `example_m6A_naive_gli36_BED` (a built-in example dataset) as the first argument to `annotate_m6a()`, but never clarifies which output from `create_bed_file()` to use in a real analysis. `bed_output$m6a_df_with_genomic_coordinates` (the natural choice) fails with `Missing required m6A coordinate columns in m6a_df` because it uses `genomic_pos` rather than `start`/`end` column names. The correct substitute is `bed_output$bed_df`, which is in BED6 format and has the `chr`, `start`, `end`, `strand` columns `annotate_m6a()` expects. This script uses `bed_output$bed_df` accordingly.
